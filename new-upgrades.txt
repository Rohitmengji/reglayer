### Score Formula
```
Base Risk Score (0-100) =
  Σ (violation_count_for_rule × litigation_weight × impact_multiplier)
  normalized to 0-100 scale

Impact multipliers:
  critical: 2.0 | serious: 1.5 | moderate: 1.0 | minor: 0.5

Final Risk Score =
  Base Risk Score
  × industry_multiplier
  × geo_multiplier
  × recency_factor  // scans older than 90 days increase risk by 1.2×
  capped at 100

Risk Tiers:
  0-24:  LOW      (green)  "Minimal exposure"
  25-49: MODERATE (yellow) "Monitor closely"
  50-74: HIGH     (orange) "Immediate action recommended"
  75-100: CRITICAL (red)   "Severe legal exposure"

Financial Exposure Estimate:
  estimated_exposure = 
    Σ (violations_matching_rule × avg_settlement_for_rule × 0.15)
    // 0.15 = estimated probability of receiving demand letter
    // given violation profile (based on 2025 filing rates)
    capped at $500,000 (typical class action threshold)
```

```typescript
/**
```

```typescript
 * Each event's hash includes the previous event's hash,
 * creating a tamper-evident chain (like a blockchain, but simpler).
 * @throws if previous hash cannot be retrieved

export async function recordComplianceEvent(

 * Generates a SHA-256 hash of compliance event content.
 * Deterministic — same input always produces same hash.
 */

  eventType: string,
  eventData: object,
  timestamp: Date,
  previousHash: string | null
): string
```

Hash input format (deterministic serialization):
```
SHA256(
  eventType + "|" + 
  JSON.stringify(eventData, Object.keys(eventData).sort()) + "|" +
  timestamp.toISOString() + "|" +
  (previousHash ?? "GENESIS")
)
```

### CLI Commands

**reglayer check**
```
Usage: reglayer check [options]
Options:
  --url <url>              URL to scan (required)
  --threshold <score>      Minimum AIS score (default: 700, 0-1000)
  --block-on-critical      Exit 1 if ANY critical violations found
  --block-on-new           Exit 1 if violations regressed vs baseline
  --baseline <scanId>      Compare against specific previous scan
  --api-key <key>          RegLayer API key (or REGLAYER_API_KEY env)
  --api-url <url>          RegLayer instance URL (default: reglayer.app)
  --format <fmt>           Output format: text|json|github (default: text)
  --timeout <ms>           Scan timeout (default: 30000)
  --output <file>          Write JSON results to file
```

Exit codes:
  0 = passed all thresholds
  1 = score below threshold OR critical violations found OR regression
  2 = scan failed or API error

**reglayer scan**
  Runs a scan and outputs full results. No threshold blocking.
  Useful for generating reports in CI without failing the build.

**reglayer compare**
  Compares two scan IDs and outputs what changed.
  Used in release notes automation.
